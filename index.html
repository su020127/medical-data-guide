01 · Data Types

보건의료 비정형 데이터 5대 유형

가이드라인은 보건의료 데이터를 정형(Structured)과 비정형(Unstructured)으로 구분합니다. 비정형 데이터는 고정된 형식 없이 이미지·텍스트·음성 등으로 존재하며, 처리 난이도가 높습니다.

구분 🗂️ 정형 데이터 (Structured) 📂 비정형 데이터 (Unstructured)
정의 사전 정의된 스키마(행·열)로 저장 고정 형식 없이 텍스트·이미지·음성 등으로 존재
대표 예시 진단코드(KCD), 처방전, 검사수치, 청구 데이터 EMR 서술 텍스트, CT/MRI 영상, 음성 기록, 병리슬라이드
가명처리 난이도 상대적으로 용이 (값 치환·삭제·범주화) 복잡 — 형식 다양, 문맥 내 식별자 혼재
2025년 개정 특이사항 기존 표준 기법 유지 유형별 처리 시나리오 제공, 폐쇄환경 자율 수준 허용

02 · Sensitivity Levels

개인식별 위험도 3단계 분류

가이드라인은 개인정보보호법 제23조의 '민감정보'와 보건의료 특성을 결합하여 위험도를 3단계로 구분합니다. 유전체·음성·영상 등 특수 유형은 별도 최고 민감도로 지정됩니다.

개인정보보호법 제23조 — 민감정보 법적 정의
건강·성생활 정보 유전정보 생체인식정보 (지문·홍채·음성·얼굴) 범죄경력·수사 정보 사상·신념·정치적 견해 인종·민족 정보
→ 보건의료 데이터 대부분은 '건강·유전정보'에 해당 — 가명처리 또는 별도 동의 없이 제3자 제공 불가

03 · Classification Table

데이터 유형별 민감도 등급표

가이드라인에 근거한 주요 보건의료 데이터 유형별 민감도 등급과 처리 원칙입니다.

데이터 유형 세부 예시 등급 주요 식별 위험 요소 처리 방법
유전체 원시 (FASTQ) 전체 염기서열 원시 데이터 🔴 최고위험 전체 유전정보 복원 가능 가명처리 불가 — 정보주체 동의 필수
진료 상담 녹음 의사-환자 대화 오디오 🔴 최고위험 성문(Voice Print) + 민감 내용 동시 포함 STT 변환 후 텍스트 처리, 음성 변조
수술·재활 영상 얼굴·신체 노출 포함 영상 🔴 최고위험 얼굴 인식으로 직접 식별 가능 얼굴 블러·모자이크 처리 필수
정신과·심리 기록 상담 내용, 진단 소견, 입원 기록 🔴 최고위험 낙인·차별 위험, 정신건강복지법 §42 IRB 심의 필수, 별도 동의 취득
일반 진료 기록 (EMR) 소견문, 수술 기록, 퇴원 요약 🟠 높은위험 직접 기재된 개인정보, 상병명 NER 기반 식별자 마스킹, 날짜 일반화
의료 영상 (메타 포함) CT, MRI, X-ray + 환자 DICOM 헤더 🟠 높은위험 DICOM 헤더 내 직접 식별자 포함 메타데이터 삭제·치환, De-facing
병리 슬라이드 (WSI) 조직 생검 이미지 🟠 높은위험 이미지 매칭 기반 간접 재식별 레이블·메타 삭제, 폐쇄 환경 분석
유전체 (SAM/BAM/VCF) 정렬 염기서열, 변이 정보 🟠 높은위험 희귀 변이로 개인 특정 가능 희귀 변이 및 메타데이터 삭제 후 가명처리
심전도 원본 (ECG) 파형 + 환자 ID 포함 🟠 높은위험 심장 질환 이력 역추적 가능 환자 ID 삭제, 날짜 이동, 잡음 추가
처방전 (스캔) 손글씨·인쇄 처방 PDF 🟠 높은위험 투약 이력 = 진단 간접 노출 OCR 후 식별자 마스킹, 의약품명 일반화
가명처리 임상 텍스트 NER 마스킹 완료 소견문 🟡 중간위험 결합 시 재식별 위험 잔존 결합 시 재평가, DRB 심의 후 활용
유전체 (연구용 익명) 집단 GWAS, 공개 데이터셋 🟡 중간위험 재식별 기술 발전으로 주의 필요 집단 수준 집계, 개인 연계 차단
집계·통계 보고서 기관 단위 공개 통계 🟢 낮은위험 개인 식별 불가 수준 기본 안전조치 후 활용 허용
합성 (Synthetic) 데이터 GAN 생성 모의 임상 기록 🟢 낮은위험 원본 연계 없을 때 식별 불가 생성 방법론 문서화, 비식별 검증 완료
04 · Genomics Special Provision

유전체 데이터 파일 형식별 특례

가이드라인은 유전체 데이터를 최고 민감도 카테고리로 지정하고, 파일 형식에 따라 처리 방식을 구체화합니다.

FASTQ
전체 염기서열 원시 데이터. 개인의 전체 유전정보를 담고 있어 가명처리 기술로도 재식별 위험을 차단할 수 없습니다.
⛔ 가명처리 불가 — 반드시 정보주체의 명시적 동의 취득 후에만 처리
SAM / BAM
참조 게놈에 정렬된 염기서열 + 메타데이터. 희귀 변이 보유자는 집단 내에서 개인 특정이 가능합니다.
⚠️ 희귀 변이 염기서열 및 메타데이터 삭제 후 가명처리 가능
VCF
변이 정보(Variant Call Format). 개인 고유의 희귀 변이가 포함되어 있어 메타데이터 제거가 필수입니다.
⚠️ 개인 식별 가능한 희귀 변이·메타데이터 삭제 후 가명처리 가능
검사기록지
유전자 검사 소견 및 결과 텍스트. 일반 텍스트 형식이므로 NER 기반 식별자 탐지 처리가 가능합니다.
🔶 NER 기반 식별자 마스킹, 희귀 질환명 일반화 후 처리 가능
05 · Processing Procedure

가명처리 6단계 표준 절차

가이드라인이 제시하는 DRB 심의 포함 표준 처리 절차입니다. 폐쇄 분석환경에서는 합리적 수준의 자율 처리가 허용됩니다.

기법설명적용 데이터
