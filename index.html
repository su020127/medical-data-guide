4단계 민감도 등급 체계

S1 · 최고
극도 민감
개인 식별 가능 + 특별 민감 정보 결합. 유출 시 심각한 차별·낙인 우려
S2 · 높음
고도 민감
개인 식별 가능 의료 정보. 법적 보호 대상 (개인정보보호법·의료법)
S3 · 중간
일반 민감
가명·익명 처리 후에도 재식별 리스크 잔존. 보조적 통제 필요
S4 · 낮음
공개·비식별
충분한 비식별 처리 완료 또는 공개 연구용. 기본 보안만 적용

S1 극도 민감 — 해당 데이터 유형

HIV/AIDS 진단 기록 정신건강·정신과 기록 약물 남용·중독 치료 성병 관련 기록 유전자 정보 (식별 가능) 수술·상담 녹화 (얼굴 노출) 임신·낙태 기록 진료 상담 녹음

S2 고도 민감 — 해당 데이터 유형

일반 EMR/진료 기록 의료 영상 (환자 메타 포함) 생체 신호 원본 처방·투약 기록 보험 청구 서류 병리 슬라이드

S3 / S4 — 해당 데이터 유형

가명 처리 임상 텍스트 메타 제거 영상 데이터 유전체 (연구용 익명) 집계 통계 공개 연구 데이터셋 익명 합성 데이터

비정형 의료 데이터 유형별 민감도 등급

데이터 유형 세부 예시 등급 주요 근거
진료 기록 (텍스트) EMR 소견, 수술 기록, 퇴원 요약 S2 고도 의료법 §22, 개인정보보호법 §23 민감정보
정신과·심리 기록 상담 내용, 진단 소견, 입원 기록 S1 극도 낙인·차별 위험, 정신건강복지법 §42 비밀유지
일반 의료 영상 CT, MRI, X-ray (환자 메타 포함) S2 고도 DICOM 헤더 내 직접 식별자 포함
병리 슬라이드 조직 생검 이미지 S2 고도 암·희귀질환 진단 정보 포함
심전도 (ECG) 원본 파형 + 환자 ID 포함 S2 고도 심장 질환 이력 역추적 가능
생체신호 (익명) 메타 제거 후 집계 파형 S3 일반 재식별 가능성 잔존 — 보조 통제 필요
유전자 정보 (식별 가능) 개인 연계 NGS, SNP 데이터 S1 극도 개인정보보호법 §23, 생명윤리법 §15 유전정보 보호
유전체 (연구용 익명) 집단 GWAS, 공개 데이터셋 S3 일반 재식별 기술 발전으로 주의 필요
진료 상담 녹음 의사-환자 대화 오디오 S1 극도 음성 생체인식 + 민감 내용 동시 포함
수술·재활 영상 얼굴·신체 노출 포함 영상 S1 극도 얼굴 인식으로 직접 식별 가능
처방전 (스캔) 손글씨·인쇄 처방 PDF S2 고도 투약 이력 = 진단 간접 노출
보험 청구 서류 EDI·PDF 청구명세서 S2 고도 상병명·행위코드 포함
집계 통계 보고서 기관 단위 공개 통계 S4 공개 개인 식별 불가 수준 충족 시
합성 (Synthetic) 데이터 GAN 생성 모의 임상 기록 S4 공개 원본 연계 없을 때 — 생성 방법 검증 조건

민감도 등급별 처리 요건

S1
극도 민감 — 최고 수준 통제
암호화(AES-256 이상) 저장 및 전송 · 접근자 최소화(Need-to-know) · 접근 로그 전수 감사 · IRB/DPO 사전 승인 필수 · 국외 이전 원칙 금지 · 데이터 처리 목적 외 사용 엄금
S2
고도 민감 — 강화 통제
암호화 저장 · 역할 기반 접근 통제(RBAC) · 동의서 확보 · 접근 로그 정기 감사 · 가명 처리 후 2차 활용 가능 · 보존 기간 법정 기한 준수
S3
일반 민감 — 표준 통제
기본 암호화 · 접근 통제 · 재식별 위험 평가 주기적 실시 · 연구·분석 목적 사용 시 데이터 관리자 승인
S4
공개·비식별 — 기본 보안
일반 접근 통제 · 출처 기록 유지 · 합성 데이터는 생성 방법론 문서화 · 공개 전 비식별 검증 완료 확인
